1. Extract

2. Adapt

  • Replace panel-local layout/renderer logic with widget calls.

3. Validate

  • Teletext page render parity (color, flash, mosaic blocks).

4. Publish

  • Pin frontend to @udos package versions.
  • Remove duplicated local grid-algebra render loops.
